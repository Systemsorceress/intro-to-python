PART 2: COMPARISON 1 / 2

Comparison Operators

Comparison operators compare two values. Python answers with a Boolean value: True or False.

== Equal to (5 == 5 → True)
!= Not equal to (5 != 3 → True)
> Greater than (7 > 4 → True)
< Less than (2 < 8 → True)
>= Greater than or equal (5 >= 5 → True)
<= Less than or equal (4 <= 7 → True)

⚠️ Remember: = is for assignment, while == is for checking equality!

PART 5: EXPRESSIONS 1 / 2

Combining Values & Order of Operations

Expressions can combine numbers, variables, and operators. Python follows math order rules (PEMDAS), so parentheses () run first!

a = 10
b = 4

result = (a + b) * 2
print(result)

Calculation Steps:

  1. Parentheses first: (10 + 4) → 14
  2. Multiplication next: 14 * 2 → 28
