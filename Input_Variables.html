DEFINITION

🧠 NOW: What Is a Variable?

📦

A variable is a named place where we store information so we can use it later. 

Variable = Name + Stored Information
WHY VARIABLES?

🔁 Before vs. After

❌ BEFORE
input("What is your name? ")
Information is received, but we don't give it a name to reuse.
✅ AFTER
name = input("What is your name? ")
Information is stored in name so we can reuse it later.
